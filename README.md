# MIDIShare (English)
MIDIShare is an web application which can convert your MIDI into Tone.js-compatible JSON and upload it to a JSON storing service with ease.

### Requirements
Node.js 18+

### Building
If you use NPM, you can build it by running the following commands below after cloning this repository.
```bash
npm i
npm run build
```
To try it locally, run `npm run dev` after installing the dependecies.

# MIDIShare (日本語)
ローカルでMIDIをJSON形式に変換し、外部の保管サービスにアップロードする作業を簡単にするウェブアプリです。

### 必要要件
Node.js 18以上

### ビルド
NPMを使用する場合は、このリポジトリをクローンして、リポジトリフォルダ内で以下のコマンドを実行するだけでビルドできます。
```bash
npm i
npm run build
```
ローカルで試す場合は、依存関係のインストール後に`npm run dev`を実行します。
